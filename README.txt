K-BOOTH FIRST WORKING PROTOTYPE

Included:
- Three original sample themes
- Front-camera permission and live preview
- Pose prompts and countdown
- Four photo captures
- Automatic four-cut layout
- JPG download
- Photos remain in the browser session; no upload/server is used

Not included yet:
- Idol photographs, official logos or artist branding
- Live/AI-generated idol interaction
- Admin dashboard, accounts, database, ads or analytics

PHONE-ONLY PUBLISHING
1. Download and unzip this project on your Android phone.
2. In Chrome, open https://github.com/ and sign in.
3. Create a repository named kbooth-mvp. Choose Public for the simplest free setup; do not upload private/licensed assets to a public repo.
4. In the repo choose Add file > Upload files. Upload index.html, style.css and app.js. Commit.
5. Open https://dash.cloudflare.com/ and create/sign in to a free account.
6. Go to Workers & Pages > Create > Pages > Connect to Git.
7. Select kbooth-mvp. Leave the build command blank. Set build output directory to / (repository root, if requested). Deploy.
8. Open the generated HTTPS pages.dev URL in Chrome on your phone.
9. Tap Start camera and allow camera access.

If the Cloudflare screen looks different, send a screenshot before choosing settings. Camera access generally needs HTTPS; a local file preview may not work.
